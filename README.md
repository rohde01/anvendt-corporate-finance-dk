# Anvendt Corporate Finance

Repository til seminaret i **Anvendt Corporate Finance** ved Økonomisk Institut, Københavns Universitet.

## Indhold

Dette repository samler materiale til seminaret, herunder data, analyser, beregninger og opgaveudkast.

## Struktur

```
.
├── data/        # Rådata og behandlede datasæt
├── analyse/     # Scripts og notebooks til analyser
├── opgave/      # Seminaropgave og udkast
└── README.md
```

## Forfatter

Udarbejdet som en del af seminaret i Anvendt Corporate Finance, Københavns Universitet.
